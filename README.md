# mini-sate

两个轻量、纯前端、单文件的日常工具，所有数据只保存在浏览器本地（localStorage），无需后端、无需注册，打开即用。

## 项目列表

| 文件 | 功能 | 说明 |
| --- | --- | --- |
| `fitness-tracker.html` | 健身 & 饮食日记 | 记录训练与饮食，追踪每日热量、蛋白质、饮水和运动时长目标 |
| `study-habit.html` | 学习小站 | 番茄钟 + 学习统计，专注计时、快捷计时、图表分析与桌面提醒 |

### 健身 & 饮食日记

- 训练记录：力量训练等训练类型、时长与备注
- 饮食记录：每餐摄入与热量
- 每日目标：热量、蛋白质、饮水、运动时长，实时进度条
- 概览与历史：今日数据汇总、历史记录管理
- 深色主题，适配移动端

### 学习小站

- 番茄钟：25 分钟专注 / 5 分钟休息，支持自定义与长休息
- 快捷计时器：多种预设时长一键开始
- 今日学习统计：专注时长、完成轮次
- Chart.js 图表：学习趋势可视化
- 浏览器桌面通知：一轮结束时提醒
- 横屏大时钟模式

## 快速开始

两种方式任选其一：

1. 直接下载对应 HTML 文件，用浏览器打开即可。
2. 克隆仓库后本地起一个静态服务：

```bash
git clone https://github.com/<你的用户名>/mini-sate.git
cd mini-sate
python -m http.server 8000
# 浏览器访问 http://localhost:8000/fitness-tracker.html
```

## 技术栈

- 原生 HTML / CSS / JavaScript
- Tailwind CSS（CDN）
- Chart.js（CDN）
- localStorage 本地存储

## 数据与隐私

所有数据仅保存在你自己浏览器的 localStorage 中，不会上传到任何服务器。清除浏览器数据或更换浏览器会导致数据丢失，建议定期导出备份（如有需要可自行扩展导出功能）。
